# Phase 6 - CI/CD GitHub Actions + KPI consolidation
Timestamp: 20260207_225301_EuropeParis

## Faits (preuves/logs)
- Ajout du script `tools/collect_kpi.py` (consolidation KPI).
- Ajout du workflow `.github/workflows/quality.yml`.

## Mode d'emploi
- Le workflow `quality` se declenche a chaque push.
- Jobs:
  - `unit-tests`: pytest + junit + coverage
  - `debt-tech`: flake8/pylint/radon
  - `perf-k6`: demarre uvicorn + k6 smoke
  - `consolidate-kpi`: agrege les rapports bruts en KPI
- Artifacts produits:
  - `raw-unit`, `raw-debt`, `raw-perf` (reports/raw)
  - `consolidated-kpi` (reports/consolidated)

## Interpretation
- La consolidation KPI gere les fichiers manquants avec `NON_VERIFIABLE`.
- Le job perf depend d'un MySQL local sur 3308 (service GH Actions) et peut echouer si la DB est indisponible.

## Recommandations
- Si l'app supporte un DB URL configurable, injecter un env pour simplifier la CI.
- Ajouter un gate si besoin (ex: coverage min) apres stabilisation.
